# LLD Practice Platform Server

Please refer to the comprehensive project [README.md](../README.md) in the root directory for architecture diagrams, end-to-end flow, data models, API documentation, and setup instructions.

### Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Seed database
npm run seed

# 3. Start development server
npm run dev

# 4. Type check & build
npm run typecheck
npm run build
```
